# DN5: vremenske postaje

Modul za beleženje temperaturnih meritev vremenskih postaj in izpis statistike.

## Zagon

    go run ./cmd/main --minTemp -50 --maxTemp 50 --stMeritev 3

## Uporaba paketa

    go get github.com/vamp3k/dn5@v1.0.1

Dokumentacija: https://pkg.go.dev/github.com/vamp3k/dn5/vreme
